Fixed by adding `style={{flex:1, width:'100%'}}` to every ScrollView (`start.tsx`, `scan.tsx`, `scan-results.tsx`, `onboarding.tsx`) so it stretches first, then `maxWidth` (raised to 1080 from 800) correctly caps it. Verified visually: desktop now fills the width; the fix is a no-op below `MaxContentWidth` so phones are provably unaffected (same reasoning noted in-session, browser window in this session wouldn't shrink below ~1536px to screenshot-prove it, but the CSS math is deterministic). Also added `preserveAspectRatio="none"` to `CurveBand`'s `<Svg>` — without it, a fixed-height viewBox letterboxes on any container wider than its native aspect ratio, which independently squished the charts.
