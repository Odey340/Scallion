Fixed by adding `style={{flex:1, width:'100%'}}` to every ScrollView (`start.tsx`, `scan.tsx`, `scan-results.tsx`, `onboarding.tsx`) so it stretches first, then `maxWidth` (raised to 1080 from 800) correctly caps it. Also added `preserveAspectRatio="none"` to `CurveBand`'s `<Svg>` — without it, a fixed-height viewBox letterboxes on any container wider than its native aspect ratio, which independently squished the charts.
